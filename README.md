# Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС.

## Этап 1: REPL

Минимальный прототип с поддержкой:
- Интерактивного режима
- Парсинга аргументов с кавычками
- Команд-заглушек: `ls`, `cd`
- Команды `exit`

## Этап 2: Конфигурация

Добавлена поддержка параметров командной строки и стартовых скриптов:
- `--vfs-path` — путь к физическому расположению VFS
- `--script` — путь к стартовому скрипту
- Поддержка комментариев в скриптах (синтаксис `#`)
- Отладочный вывод конфигурации при запуске
